# Sistema Acadêmico DS II

Projeto desenvolvido para a disciplina de Desenvolvimento para Servidores II, do curso de Sistemas para Internet da Fatec São Roque.

## Objetivo

Desenvolver gradualmente um sistema acadêmico web que permita cadastrar e consultar alunos, disciplinas, usuários e notas.

O projeto será desenvolvido por etapas, começando com JavaScript e evoluindo para uma aplicação com frontend, backend e banco de dados.

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MySQL
- JWT
- Git e GitHub

## Estrutura do projeto

- **frontend:** interface do sistema, desenvolvida com HTML, CSS e JavaScript.
- **backend:** responsável pela API e pelas regras do servidor.
- **database:** arquivos e scripts relacionados ao banco de dados.
- **docs:** documentação e registros do desenvolvimento.

## Etapas de desenvolvimento

O sistema será construído em diferentes versões:

- **Versão 0.1:** cadastro de alunos utilizando JavaScript, MVC e JSON.
- **Versão 0.2:** criação da interface com HTML, CSS e DOM.
- **Versão 0.3:** armazenamento local dos dados com localStorage.
- **Versão 1.0:** criação do servidor e da primeira API com Node.js.

As próximas versões irão adicionar novas funcionalidades e integrar as diferentes partes da aplicação.

## Situação atual

O projeto está na fase inicial. Até o momento, foi criada a estrutura de pastas e arquivos que será utilizada durante o desenvolvimento.

As funcionalidades serão implementadas gradualmente conforme o andamento das aulas.
